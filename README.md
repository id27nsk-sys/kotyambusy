# 🐾 КОТЯМБУСЫ!!! v2.1m

Интерактивное веб-приложение про котиков с элементами кликера, коллекционированием и ранговой системой.

## 🛠 Текущий функционал (Что уже работает)

### 1. Визуальная часть
- **Адаптивный дизайн:** Интерфейс корректно отображается на ПК и смартфонах (исправлен эффект «спичечного коробка»).
- **Фавикон:** Установлена кастомная иконка лапки из файла `images/favicon.png`.
- **Темы:** Поддержка светлой и тёмной тем оформления.
- **Модальные окна:** Галерея и статистика открываются в плавных всплывающих окнах.

### 2. Игровые механики
- **Кликер:** Начисление «Кото-коинов» при взаимодействии с фото котика.
- **Табы (Персонажи):** Переключение между котиками (Бася, Савелий) и возможность загрузить своего котика.
- **Прогресс и Ранги:** Шкала опыта, которая заполняется при кликах, и автоматическая смена рангов (от «Новичка» до «Мастера»).
- **Золотой режим:** Визуальный эффект (фильтр sepia/gold) для изображения котика при достижении определённых условий.

### 3. Эффекты
- **Лапки при клике:** Визуальный эффект вылетающих лапок (paw-particles) в месте нажатия курсора/пальца.
- **Анимации:** Плавные переходы, анимация «появления» достижений и пульсация кнопок.

---

## 📋 Техническое устройство
- **HTML5:** Семантическая разметка, использование Meta Viewport для адаптивности.
- **CSS3:** Flexbox для центрирования, CSS-переменные для тем, Media-запросы для мобильных устройств.
- **JavaScript (Vanilla):** Логика игры без сторонних библиотек. Работа с LocalStorage (для сохранения прогресса).

## 📂 Структура проекта
- `index.html` — основная разметка и структура.
- `style.css` — все стили, темы и адаптивные медиа-запросы.

- `images/` — папка с фотографиями котиков и иконками.
