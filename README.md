# 🐾 КОТЯМБУСЫ!!! v2.4 «Mobile Ultra»

Интерактивное веб-приложение-кликер, полностью оптимизированное под пользовательский опыт на смартфонах (Mobile-First).

## 🚀 Что нового в v2.4 (Текущая версия)

### 1. Тактильный отклик (Haptic Feedback) 📳
- Интегрирована вибрация при клике на котика и достижении новых рангов. Теперь игра "ощущается" физически на смартфонах.

### 2. Защита от фантомных зумов 🚫🔍
- Использование `touch-action: none` и расширенных Meta-тегов предотвращает нежелательное масштабирование страницы браузером при сверхбыстром кликанье.

### 3. Зона досягаемости (Thumb Zone) 🤳
- Интерфейс на мобильных устройствах прижат к нижней части экрана. Это позволяет управлять всеми функциями (смена кота, темы, сброс) одной рукой.

### 4. Оптимизация Tap Zones 🎯
- Увеличены области нажатия для всех кнопок и ссылок (минимум 44-48px). Больше никаких случайных промахов мимо кнопок "Галерея" или "Рекорды".

### 5. Живой рандомный фон 🌈
- При каждой смене котика или загрузке своего фото генерируется уникальный пастельный градиент.

---

## 🛠 Технический стек
- **HTML5:** Семантическая разметка + PWA-ready viewport.
- **CSS3:** Flexbox, CSS-переменные, сложные радиальные градиенты, Hardware Acceleration (`will-change`).
- **JavaScript (Vanilla):** Pointer Events API для мгновенного отклика (без задержки 300мс), Vibration API, FileReader API для работы с фото.

## 🏆 Система рангов
1. **Новичок** (0+) ☁️
2. **Любитель** (100+) 🌟
3. **Мастер** (200+) 🔥
4. **Легенда** (300+) 👑
5. **БОГ КОТОВ** (500+) ✨ — активируется "Золотой режим" (Golden Filter).

## 📂 Структура проекта
- `index.html` — Структура и мета-данные.
- `style.css` — Стили, мобильная адаптация и анимации.
- `script.js` — Игровая логика, эффекты и работа с памятью.
- `images/favicon.png` — Единый графический ресурс для иконки сайта и частиц-лапок.
