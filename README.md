Интерактивный кликер-фонд для реальных котов **Баси** и **Савелия**.

* **Classic Layout:** Вертикальная вёрстка с акцентом на центральный Посейдонов круг.

* **Stable Core:** Исправлены пути к папкам `images/cats/` и логика сохранения данных.
* **Reset System:** Кнопка полной очистки кэша и прогресса в подвале.
