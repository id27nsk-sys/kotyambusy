# 🐾 КОТЯМБУСЫ!!! v2.4.2 «Smart Switcher»

Эта версия фиксирует исправленную логику переключения персонажей и цикличную смену фотографий.

## 💾 Технический Snapshot v2.4.2
- **Смена фото:** Кнопка `#changeCatButton` теперь циклично переключает фото Баси и Савелия из локальных массивов. Для "Своего котика" открывает системный выбор файла.
- **Индикация персонажа:** Исправлено отображение русского имени кота в счетчике (Бася / Савелий).
- **Mobile First:** Сохранены тактильная отдача (вибрация), защита от зумов и привязка интерфейса к "Thumb Zone" (низу экрана).
- **Кэширование:** Все ссылки обновлены до версии `?v=2.4.2`.

## 🛠 Текущая логика в `script.js`
- `photoIndexes`: Объект, хранящий текущий номер фото для каждого кота, чтобы при переключении табов возвращаться к последнему открытому фото.
- `catImages`: Массивы путей к файлам. При добавлении новых фото в папки `images/cats/` необходимо обновлять эти массивы.

## 📂 Проверка перед пушем
1. Нажать `F6` в Notepad++ (скрипт SyncCats).
2. Дождаться сообщения `Everything up-to-date`.
3. Очистить кэш на смартфоне (Инкогнито).
