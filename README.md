# 🐾 КОТЯМБУСЫ!!! v2.8.3 «Stable Recovery»

Интерактивный кликер про баланс между котами **Басей** и **Савелием**.

### 🛠 Как это работает:
1. **Баланс (Шкала совести):** Нельзя гладить одного кота чаще другого более чем на 30 раз. Иначе — блок.
2. **Сохранение:** Весь прогресс (монеты, клики) пишется в `LocalStorage`.
3. **Графика:** Используются оригинальные файлы `b01.png` и `s01.png`.

### 📱 Мобильная версия:
Добавлена поддержка `viewport-fit=cover` и отключено масштабирование для стабильной игры на смартфонах.

### 🚀 Установка:
Просто закинь файлы в корень репозитория. GitHub Pages подхватит их автоматически.
