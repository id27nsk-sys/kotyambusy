# 🐾 КОТЯМБУСЫ!!! v2.3

Интерактивное веб-приложение про котиков. Оптимизировано для смартфонов и ПК.

## 🌟 Что нового в v2.3
- **Живой фон:** Реализована система случайных пастельных градиентов, которые меняются при каждом переключении котика или загрузке своего фото.
- **Mobile First 2.0:** Улучшена обработка касаний (`pointerdown`) для мгновенного отклика лапок на смартфонах.
- **Сброс кэша:** Добавлена система версионности файлов (`?v=2.3`) для гарантированного обновления кода у всех пользователей.
- **Унификация лапок:** Теперь при клике вылетают рыжие лапки, идентичные фавикону сайта.

## 🛠 Текущий функционал
- **Кликер:** Начисление кото-коинов и прокачка рангов.
- **Персонажи:** Переключение между Басей, Савелием и загрузка собственного котика через галерею.
- **Ранговая система:** От «Новичка» до «БОГА КОТОВ» с активацией золотого режима на 500 кликах.
- **Темы:** Полноценная тёмная и светлая темы.

## 📂 Структура проекта
- `index.html` — Структура приложения.
- `style.css` — Адаптивные стили и анимации.
- `script.js` — Игровая логика и генератор фонов.
- `images/` — Ресурсы (фото котов и `favicon.png`).

## 🚀 Инструкция по обновлению (для разработчика)
Для синхронизации с GitHub используется макрос в Notepad++:
1. Внести правки в код.
2. Запустить макрос `СИНХРОНИЗИРОВАТЬ КОТОВ 🐾` (F6).
3. Проверить результат на сайте в режиме инкогнито.
