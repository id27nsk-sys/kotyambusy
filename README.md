# 🐾 КОТЯМБУСЫ!!! v2.6 «Collector's Edition»

## 💾 Технический Snapshot v2.6
- **Система коллекционирования:** Возвращены счетчики в раздел «Галерея». Скрипт отслеживает уникальные просмотры фотографий через массив `seenPhotos`.
- **Бонусная механика:** За открытие всех фотографий одного персонажа (Бася или Савелий) игроку начисляется бонус **+500 кото-коинов**.
- **Локальное хранение:** Прогресс коллекции сохраняется в `localStorage`.
- **Авто-сканер:** Продолжает работу в фоновом режиме, автоматически определяя общее количество фото для расчета прогресса галереи.

## ✅ Протестировано
1. Начисление бонуса при достижении лимита массива.
2. Сохранение и отображение счетчиков `X / Y` в уведомлении галереи.
3. Мгновенная вибрация при получении бонуса.
