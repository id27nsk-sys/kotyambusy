# 🐾 КОТЯМЬБУСЬ! v3.0 Live & Real

Интерактивный кликер-блог про жизнь котов **Баси** и **Савелия**.

## 🚀 Новое в v3.0:
- **Система Лапок:** Вернулись визуальные эффекты при каждом клике!
- **Механика «Совести»:** Не кликай слишком часто, иначе кот обидится.
- **Риск «Кусь»:** При низкой совести есть шанс получить штраф -10 монет 🩹.
- **Live-Фото:** Теперь фото подгружаются из реальной жизни (папки `img/live/`).

## 🛠 Как добавить свои фото:
1. Открой приложение GitHub на телефоне.
2. Загрузи новые фото Баси в `img/live/basya/` или Савелия в `img/live/saveliy/`.
3. Обнови путь к фото в `script.js` в объекте `KOTYAMBUS_CORE`.
