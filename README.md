# 🐾 КОТЯМБУСЫ!!! v2.8.3 «Stable Recovery»

Интерактивный кликер про Басю и Савелия. Построен на балансе внимания между двумя котами.

## ✨ Основные фичи
- **Система Баланса:** Шкала совести показывает, кого вы гладите чаще. Не допускайте разницы > 30 кликов!
- **Spring Physics:** Приятная пружинная анимация карточек при нажатии.
- **Haptic Feedback:** Тактильная отдача (вибрация) при клике на мобильных устройствах.
- **LocalStorage:** Весь прогресс (монеты и клики) сохраняется автоматически.

## 🛠 Техническая информация
- **Верстка:** Адаптивный Flexbox с поддержкой Safe Areas для смартфонов.
- **Пути:** Изображения подгружаются из директории `/images/`.
- **Производительность:** Использование `pointer-events` и `touch-action` для быстрого отклика без задержек.

## 📁 Структура
- `index.html` — Структура приложения.
- `style.css` — Дизайн и анимации.
- `script.js` — Игровая логика.
- `favicon.ico` — Иконка проекта.
