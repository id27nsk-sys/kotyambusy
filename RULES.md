# 🐾 Глобальный регламент (STRICT_MODE) 🐾

Проект защищен данным файлом. Любое изменение обязано соответствовать:
- **RULES_ACCUMULATION_ONLY**: Правила только накапливаются.
- **DESTRUCTIVE_EDIT_FORBIDDEN**: Запрещено удалять фундаментальную логику клика и циклы фото.
- **NAME_STRICT**: Название всегда строго **🐾КОТЯМБУСЫ🐾**.
- **VISUAL_PAWS_CONSTANT**: Эмодзи 🐾 обязательны во всех ключевых узлах.
- **Hero Selector**: Мгновенное переключение между Басей (индекс `b`) и Савелием (индекс `s`).
- **Glassmorphism 2.0**: Современный UI с эффектом матового стекла и глубокими тенями.
- **SHAPE_STRICT**: Окно отображения героя всегда имеет форму идеального круга.
- **ACTION_CENTERED**: Фото героя — главный узел взаимодействия. Кнопка КУСЬ упразднена.
- **PAW_PARTICLE_STRICT**: Визуальный эффект вылетающих эмодзи 🐾 при поглаживании.
- **SYNC_AUDIT_STRICT**: Любой ответ обязан содержать сверку текущего кода с изменениями.
- **MILESTONE_CELEBRATION**: Каждые 100 накопленных поглаживаний сопровождаются Glassmorphism-уведомлением.
- **PHOTO_CYCLE_STRICT**: Каждые 5 поглаживаний фото героя меняется на следующее.
- **CURSOR_LOCALIZATION**: Кастомный курсор-лапка `paw02.png` активен только при наведении на круг фото героя.
- **ADAPTIVE_STRICT**: Интерфейс обязан быть стабилен от 240px до 1024px. Запрещено синее выделение (tap-highlight) при клике.
- **DYNAMIC_DETECT_STRICT**: Лимиты на количество фото в коде запрещены. Система обязана автоматически определять размер архива (b01-bXX / s01-sXX) через обработку ошибок загрузки.
