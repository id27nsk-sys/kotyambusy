# 🐾 Глобальный регламент (STRICT_MODE) 🐾

Проект защищен данным файлом. Любое изменение обязано соответствовать:
- **RULES_ACCUMULATION_ONLY**: Правила только накапливаются.
- **DESTRUCTIVE_EDIT_FORBIDDEN**: Запрещено удалять фундаментальную логику клика и циклы фото.
- **NAME_STRICT**: Название всегда строго **🐾КОТЯМБУСЫ🐾**.
- **VISUAL_PAWS_CONSTANT**: Эмодзи 🐾 обязательны во всех ключевых узлах.
- **Hero Selector**: Мгновенное переключение между Басей (индекс `b`) и Савелием (индекс `s`).
- **Glassmorphism 2.0**: Современный UI с эффектом матового стекла и глубокими тенями.
- **SHAPE_STRICT**: Окно отображения героя всегда имеет форму идеального круга.
- **ACTION_CENTERED**: Фото героя — главный узел взаимодействия (поглаживание генерирует койны).
- **PAW_PARTICLE_STRICT**: Визуальный эффект вылетающих эмодзи 🐾 при поглаживании.
- **SYNC_AUDIT_STRICT**: Любой ответ обязан содержать таблицу сверки текущего кода.
- **MILESTONE_CELEBRATION**: Каждые 100 поглаживаний сопровождаются уведомлением.
- **PHOTO_CYCLE_STRICT**: Каждые 5 поглаживаний фото героя меняется на следующее.
- **CURSOR_LOCALIZATION**: Кастомный курсор-лапка активен только внутри круга фото.
- **ADAPTIVE_STRICT**: Интерфейс стабилен от 240px до 1024px. Запрещено синее выделение (tap-highlight).
- **PRELOAD_DETECTION_STRICT**: Система обязана сканировать архив героя сразу при загрузке, чтобы пользователь видел реальное количество фото (X из Y) немедленно.
- **FLUID_STRESS_TEST**: Обязательна проверка на Micro-Mobile (240px) без вылета элементов. Использование `aspect-ratio: 1/1` для круга обязательно.
- **BOTTOM_VISIBILITY_STRICT**: Все элементы управления (СБРОС, ФОТО) должны быть видимы или доступны через скролл на экранах высотой от 480px. Обязательно использование `padding-bottom` для компенсации системных панелей мобильных браузеров.
- **DATA_INTEGRITY_STRICT**: Все данные из localStorage обязаны проходить валидацию (isNaN check) и приведение к типу Number/Boolean перед использованием в логике.
- **ID_NAMESPACE_CONSTANT**: При добавлении новых элементов (меню, магазин) использовать префиксы (например, shop-, cat-), чтобы исключить конфликты с ядром системы.
- **ASYNC_GUARD_STRICT**: Любая асинхронная операция (сканирование, загрузка фото) должна иметь флаг блокировки (isUpdating) и лимит попыток, чтобы предотвратить утечку памяти и зависание интерфейса.
