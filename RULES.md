# 🐾 Глобальный регламент (STRICT_MODE) 🐾

Проект защищен данным файлом. Любое изменение обязано соответствовать:

## 🔒 Фундаментальные принципы (IMMUTABILITY_STRICT)

- IMMUTABILITY_STRICT: УДАЛЕНИЕ ЛЮБЫХ СТРОК ИЗ ПРАВИЛ КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО.
- RULES_ACCUMULATION_ONLY: Правила только накапливаются. Новые правила добавляются в конец файла.
- DESTRUCTIVE_EDIT_FORBIDDEN: Запрещено удалять фундаментальную логику проекта.
- ASSET_IMMORTALITY_STRICT: УДАЛЕНИЕ ЛЮБЫХ ПУТЕЙ ИЗ БЛОКА STRICT_PATHS ЗАПРЕЩЕНО.

## 🎨 Визуальные и UI-правила

- NAME_STRICT: Название всегда строго 🐾КОТЯМБУСЫ🐾. Используется в `<title>` и `<h1>`.
- VISUAL_PAWS_CONSTANT: Эмодзи 🐾 обязательны во всех ключевых узлах (кнопки, заголовки, уведомления).
- Glassmorphism 2.0: Современный UI с эффектом матового стекла (backdrop-filter: blur(20px), полупрозрачные фоны).
- SHAPE_STRICT: Окно героя всегда имеет форму идеального круга (border-radius: 50%).
- ACTION_CENTERED: Фото героя — главный и единственный узел взаимодействия. Весь игровой процесс завязан на клик/тап по кругу.
- CURSOR_LOCALIZATION: Кастомный курсор «Лапка» 🐾 активен ТОЛЬКО внутри круга фото.
- DESKTOP_VIEW_CENTERED_STRICT: На десктопах игровой узел расположен строго по центру экрана.
- HERO_SCALE_STRICT: Размер круга героя оптимизирован под вьюпорт: `min(65vw, 45vh)` на мобильных, `clamp(350px, 50vh, 500px)` на десктопе.
- GLOW_CELEBRATION: Золотое сияние (класс `glow-active`) при поглаживаниях, кратных 30. Длительность — 3 секунды.
- FADE_TRANSITION_STRICT: 🆕 Смена фото сопровождается двойным плавным переходом:
  - Fade-out (исчезновение) старого фото — 0.3 секунды
  - Fade-in (проявление) нового фото — 0.3 секунды
  - Общая длительность цикла смены — 0.6 секунды

## 📱 Адаптивность

- ADAPTIVE_STRICT: Интерфейс стабилен от 240px до 1024px. Отключён `tap-highlight`.
- FLUID_STRESS_TEST: Проверка Micro-Mobile (240px). Использование `aspect-ratio: 1/1` для круга.
- BOTTOM_VISIBILITY_STRICT: Доступность всех кнопок на экранах от 480px высотой.
- VERTICAL_ECONOMY_STRICT: На низких экранах (высота < 600px) отступы максимально сокращаются (--safe-gap: 5px).
- DYNAMIC_PROPORTION_STRICT: На Desktop (min-width: 1024px) верстка масштабируется от vh, на Mobile — от vw.
- MOBILE_FLUID_SYMMETRY_STRICT: Учет `safe-area-inset`. Суммарная высота всех элементов < 95vh.

## 🎮 Игровая механика

- Hero Selector: Мгновенное переключение между Басей (b) и Савелием (s). При переключении счётчик `lastTapTime` сбрасывается, также применяется Fade-in анимация.
- PAW_PARTICLE_STRICT: Визуальный эффект вылетающих 🐾 при каждом поглаживании. Максимум 20 частиц одновременно.
- MILESTONE_CELEBRATION: Каждые 100 поглаживаний сопровождаются всплывающим уведомлением (toast).
- PHOTO_CYCLE_STRICT: Каждые 5 поглаживаний фото героя меняется на следующее по порядку. Цикл зациклен.
- PROGRESS_ACCUMULATION_STRICT: Счётчик открытых фото (`maxUnlocked`) не сбрасывается при завершении цикла и сохраняется в `localStorage`.
- ZEN_DASHBOARD_STRICT: Статистика отображается лаконичной строкой под заголовком в формате: `🐾 {total} | Фото: {unlocked}/{totalPhotos}`.
- DATA_INTEGRITY_STRICT: Валидация всех данных из `localStorage` перед использованием:
  - Обёртка в `try...catch` для JSON-парсинга.
  - Проверка типов (числа должны быть числами, объекты — объектами).
  - Санитизация: приведение к безопасному диапазону (например, `maxUnlocked` не может быть больше 100 и меньше 1).
  - Использование функции `sanitizeNumber()` для всех числовых значений.

## ⚡ Спецэффекты

- KUS_ATTACK_STRICT: Только для Баси (b). Срабатывает НЕ случайно, а в зависимости от ритма поглаживаний:
  - Слишком быстро (< 150 мс между кликами) → «Кусь» от перевозбуждения
  - Слишком медленно (> 3000 мс между кликами) → «Кусь» от обиды
  - Золотая середина (150–3000 мс) → нормальное поглаживание
- KUS_SPAM_PROTECTION_STRICT: 🆕 Клики с интервалом менее 50 мс игнорируются (защита от спама и случайных срабатываний).
- KUS_INDICATOR_STRICT: Цвет рамки вокруг фото Баси визуально показывает «опасную зону»:
  - Красный — слишком быстро или слишком медленно
  - Жёлтый — на грани
  - Зелёный — идеальный ритм
- KUS_BLOCK_STRICT: Во время анимации «Куся» (500 мс) все поглаживания игнорируются. Клики не увеличивают счётчик и не создают частицы.
- SCREEN_SHAKE_STRICT: Резкая тряска экрана (`body.shake-effect`) при Кусе. Длительность анимации — 500 мс (синхронизирована с JS).
- IMPACT_DYNAMICS_STRICT: Эффект «Куся» должен быть молниеносным — общая длительность 500 мс, после чего всё возвращается в норму.
- SOFT_TRANSITION_STRICT: Мягкий визуальный переход (fade) 0.3с для циклов смены фото.
- ANIMATION_GUARD_STRICT: Флаг `isUpdating` защищает от одновременного запуска нескольких анимаций (смена фото, Кусь). Флаг `isKusActive` блокирует клики во время Куся.
- KUS_AFTERMATH_STRICT: После «Куся» счётчик `lastTapTime` сбрасывается, чтобы избежать цепной реакции и обеспечить корректную работу следующих атак.
- KUS_CONSISTENCY_STRICT: 🆕 Серия атак не приводит к блокировке механизма — каждый вызов корректно сбрасывает состояние и готов к следующему.
- KUS_TOUCH_SAFETY_STRICT: Функция `createPaw()` корректно обрабатывает как mouse-события, так и touch-события, с проверкой существования `e.touches` и `e.changedTouches`.

## 🛠️ Мастерская (WORKSHOP)

- ACCESS_GATE_STRICT: Вход в Мастерскую через кнопку «🧶» и секретный код `BS_0704!`.
- WORKSHOP_MANIPULATION_STRICT: Поддержка Zoom (слайдер) и Drag (перетаскивание) для центрирования фото внутри круга.
- WORKSHOP_AUTO_NAMING_STRICT: Мастерская автоматически определяет имя файла в формате `bXX.webp` или `sXX.webp`, где XX — следующий доступный номер.
- WORKSHOP_VALIDATION_STRICT: Перед экспортом проверяется наличие загруженного изображения. При отсутствии — вывод `alert`.
- WORKSHOP_EXPORT_STRICT: Экспорт происходит в формате WebP с качеством 0.8. После успешного экспорта — подтверждение закрытия.
- WORKSHOP_SAFETY_STRICT: Функция `getFileName()` обрабатывает случай `undefined totalPhotosDetected`, возвращая корректное имя файла (b01.webp).
- WORKSHOP_INPUT_VALIDATION_STRICT: Загружаемое изображение проверяется на наличие (alert при отсутствии). MIME-тип не проверяется (доверяем браузеру).

## 🛡️ Надёжность и безопасность

- PRELOAD_DETECTION_STRICT: Фоновое сканирование архива сразу при загрузке страницы. Определяется `totalPhotosDetected` для каждого героя.
- ASYNC_GUARD_STRICT: Все асинхронные операции защищены флагом `isUpdating`.
- DOM_LEAK_TEST: Запрещено накопление мусорных узлов. Частицы и тосты удаляются через `remove()`.
- OFFLINE_RESILIENCE_TEST: Система обязана сохранять стабильность при ошибках загрузки изображений (`img.onerror` обрабатывается).
- CONTRAST_ACCESSIBILITY_TEST: Текст на панелях должен сохранять высокую контрастность (светлый текст на тёмном фоне).
- MOTION_SAFETY_STRICT: Анимации (тряска экрана, fade-эффекты) отключаются при `prefers-reduced-motion: reduce`. CSS-медиавыражение добавлено в `style.css`.
- IMAGE_ERROR_HANDLING_STRICT: При ошибке загрузки следующего фото в цикле индекс `heroIndices` НЕ увеличивается, предотвращая пропуск изображений.
- RESET_INTEGRITY_STRICT: При сбросе прогресса (`resetAll`) полностью переопределяется `totalPhotosDetected` для корректного обнаружения новых файлов в архиве. Запрещено использовать `localStorage.clear()` — удаляются только ключи приложения.

## 🛡️ Безопасность событий (EVENT_SECURITY)

- NO_INLINE_HANDLERS_STRICT: Все обработчики событий назначаются через `addEventListener` в JS-файле. Inline-атрибуты (`onclick`, `oninput` и др.) в HTML запрещены.
- TITLE_SANITIZATION_STRICT: При обновлении `document.title` числовые значения проходят санитизацию (удаление всех нецифровых символов).
- LOCALSTORAGE_ISOLATION_STRICT: При сбросе прогресса (`resetAll()`) удаляются ТОЛЬКО ключи приложения (`coins`, `coins_b`, `coins_s`, `maxUnlocked`). Использование `localStorage.clear()` запрещено.
