# 🐾 Глобальный регламент (STRICT_MODE) 🐾

Проект защищен данным файлом. Любое изменение обязано соответствовать:
- **IMMUTABILITY_STRICT**: УДАЛЕНИЕ ЛЮБЫХ СТРОК ИЗ ПРАВИЛ КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО. Правила могут только дополняться.
- **RULES_ACCUMULATION_ONLY**: Правила только накапливаются.
- **DESTRUCTIVE_EDIT_FORBIDDEN**: Запрещено удалять фундаментальную логику.
- **NAME_STRICT**: Название всегда строго **🐾КОТЯМБУСЫ🐾**.
- **VISUAL_PAWS_CONSTANT**: Эмодзи 🐾 обязательны во всех ключевых узлах.
- **Hero Selector**: Мгновенное переключение между Басей (`b`) и Савелием (`s`).
- **Glassmorphism 2.0**: Современный UI с эффектом матового стекла.
- **SHAPE_STRICT**: Окно героя всегда имеет форму идеального круга.
- **ACTION_CENTERED**: Фото героя — главный и единственный узел взаимодействия.
- **PAW_PARTICLE_STRICT**: Визуальный эффект вылетающих 🐾 при поглаживании.
- **SYNC_AUDIT_STRICT**: Любой ответ обязан содержать таблицу сверки.
- **MILESTONE_CELEBRATION**: Каждые 100 поглаживаний сопровождаются уведомлением.
- **PHOTO_CYCLE_STRICT**: Каждые 5 поглаживаний фото героя меняется.
- **CURSOR_LOCALIZATION**: Лапка 🐾 активна только внутри круга фото.
- **ADAPTIVE_STRICT**: Интерфейс стабилен от 240px до 1024px. Без tap-highlight.
- **PRELOAD_DETECTION_STRICT**: Фоновое сканирование архива сразу при загрузке.
- **FLUID_STRESS_TEST**: Проверка Micro-Mobile (240px). Использование `aspect-ratio: 1/1`.
- **BOTTOM_VISIBILITY_STRICT**: Доступность всех кнопок на экранах от 480px высотой.
- **DATA_INTEGRITY_STRICT**: Валидация всех данных из localStorage перед использованием.
- **ASYNC_GUARD_STRICT**: Асинхронные операции защищены флагом `isUpdating`.
- **PROGRESS_ACCUMULATION_STRICT**: Счетчик открытых фото не сбрасывается при завершении цикла.
- **DOM_LEAK_TEST**: Запрещено накопление мусорных узлов. Элементы удаляются через remove().
- **OFFLINE_RESILIENCE_TEST**: При ошибке загрузки фото система обязана сохранять стабильность.
- **CONTRAST_ACCESSIBILITY_TEST**: Текст на панелях должен сохранять высокую контрастность.
- **GLOW_CELEBRATION**: При достижении количества поглаживаний, кратного 30, активируется золотое сияние.
- **KUS_ATTACK_STRICT**: Только для Баси (b). При достижении рандомного порога (9-19 поглаживаний) фото заменяется на KUS.jpg с кровавым свечением.
- **HAPTIC_ATTACK_STRICT**: Вибрация (100ms-50ms-200ms) при Кусе на поддерживающих устройствах.
- **HERO_SCALE_STRICT**: Размер круга героя увеличен (280px Standard / 200px Micro).
- **SCREEN_SHAKE_STRICT**: Резкая тряска экрана (body) при Кусе для всех устройств.
- **IMPACT_DYNAMICS_STRICT**: Эффект «Куся» должен быть молниеносным (500ms) и визуально экстремальным (инверсия и зум).
